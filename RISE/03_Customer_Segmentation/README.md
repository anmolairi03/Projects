# Project 3: Customer Segmentation

## Objective
Group customers into distinct marketing segments using clustering.

## Dataset
- `customer_data.csv`: Age, income, spending score, and visit frequency.

## Features
- K-Means clustering
- Elbow method to find optimal k
- 2D & 3D cluster visualizations
- Segment descriptions and marketing suggestions

## Expected Outcome
Identify 3–5 meaningful customer types for marketing or offers.
