# Project 4: COVID-19 Data Analysis

## Objective
Visualize the spread, recovery, and fatality trends of COVID-19 in India.

## Dataset
- `covid_india.csv`: Cumulative daily cases, recoveries, and deaths.

## Features
- Cumulative trends
- Daily new case analysis
- Recovery and death rates
- Narrative summary of pandemic progression

## Expected Outcome
Visual story of pandemic growth, recoveries, and death rates.
