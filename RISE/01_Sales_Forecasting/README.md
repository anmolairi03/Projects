# Project 1: Sales Forecasting

## Objective
Forecast daily sales revenue using linear regression and visualize trends.

## Dataset
- `sales_data.csv`: Daily sales transactions with product, quantity, and revenue.

## Features
- Train-test split and Linear Regression
- Plot actual vs predicted revenue
- Forecast for next 15 days
- Forecast table included

## Expected Outcome
Graphical and tabular forecasts for upcoming sales periods.
